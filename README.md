# 电商采集脚本

抖店罗盘、抖音创作者中心那几个页面的采集脚本，唯一的一份在这里。

## 怎么装

1. 浏览器装 Tampermonkey 扩展。
2. 打开 `运维空间采集-v1.2.user.js`，点 Raw，Tampermonkey 问要不要安装，点安装。
3. 以后改版不用重新装，Tampermonkey 会自己检查更新。

## 设置在哪

装好后打开罗盘或创作者中心页面，面板最下面有个“设置”区：地址和钥匙两个框，填一次点保存，存在你这台电脑的浏览器里。想改就进面板改，不用改脚本代码。

**这个仓库里没有任何账号、密码、钥匙、服务器地址。**

## 怎么改脚本

直接在 GitHub 网页上改：打开文件 → 点铅笔 → 改完保存提交。改完把文件头里的 `@version` 往上加一位。
